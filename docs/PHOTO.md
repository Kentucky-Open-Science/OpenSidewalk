# Hardware photo

`device-redacted.png` is the maintainer-supplied device photograph prepared for
public documentation using the built-in imagegen editing tool. The original is
not distributed. Serial numbers, QR/data-matrix labels and the metal module's
markings are covered. PNG ancillary metadata was removed after editing.

The result illustrates the assembled kit; an image-editing model may alter fine
lettering or texture, so use the hardware guides rather than this image as a
pinout or component-marking reference. The contributed public asset follows the
project's Apache-2.0 license; manufacturer trademarks retain their owners' rights.
